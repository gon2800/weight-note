# 체중 노트 (My Weight Log)

정호 개인용 체중·식사·음주 기록 웹앱(PWA). 시중 체중앱에서 **실제로 쓰는 기능만** 남긴 미니멀 버전.

> 이 문서는 코워크(Cowork)나 다른 도구가 프로젝트를 **처음 열어도 바로 이어서 작업**할 수 있게 만든 핸드오프 문서입니다. "여기서부터 이어서 해줘"라고 이 파일과 `index.html`을 함께 주면 됩니다.

---

## 1. 목적 / 사용자
- 사용자: 정호 1인 (개인용).
- 원칙: 기능을 늘리지 말고 **핵심 4가지 + 요청받은 확장만** 유지. 인바디/운동/사진/광고 등은 넣지 않는다.

## 2. 구현된 기능 (현재 상태)
- [x] 캘린더에서 날짜 선택 → 하단 입력 시트가 올라옴
- [x] 그 날짜에 **체중(kg)** 입력
- [x] **식사량 상/중/하** 입력
- [x] **음주 여부(안 마심 / 마심)** 입력
- [x] 기간별(1주 / 1개월 / 6개월 / 1년) **체중 꺾은선 그래프**
- [x] 꺾은선 위 **점 = 음주 표시** (마신 날 적색 dot / 안 마신 날 흰색 dot) + 기간 음주 비율 %
- [x] 꺾은선 아래 **식사량 막대 그래프** (상=3칸 / 중=2칸 / 하=1칸)
- [x] 데이터 백업(JSON 내보내기) / 복원(불러오기)
- [x] "홈 화면에 추가"용 PWA 매니페스트(단일 파일 내 생성)

## 3. 기술 스택 / 구조
- **파일 1개**: `index.html` (HTML + CSS + 바닐라 JS 전부 인라인).
- **의존성 없음**: 외부 라이브러리·CDN·빌드 과정 없음. 차트는 손수 만든 인라인 SVG.
- **저장소**: 브라우저 `localStorage` (서버 없음).
- 폰(갤럭시)/PC 브라우저에서 그대로 동작. 오프라인 완전 지원은 아직(서비스워커 미적용).

## 4. 데이터 구조
```
localStorage key: "weightNote.v1"
값: { "entries": { "YYYY-MM-DD": { "w": 90.1, "f": "상|중|하", "a": true } } }
  - w: 체중(kg, 소수1자리). 없으면 그날은 그래프에 안 그려짐(체중이 기준축).
  - f: 식사량 등급. 없으면 막대 없음.
  - a: 음주하면 true. 안 마시면 필드 자체를 저장하지 않음(기본=안 마심).
```
- 백업 JSON도 동일한 `{ entries: {...} }` 구조. 복원은 병합(merge) 방식.

## 5. 색상 / 디자인 토큰
- accent(체중선·UI): `#22A55E`
- 음주 dot: `#EF6C6C`(마심) / `#fff`+회색테두리(안 마심)
- 식사량 막대: 하 `#3FB950` · 중 `#F0B429` · 상 `#E8894A` (음주 적색과 안 겹치게 상은 주황)

## 6. 배포 파이프라인 (GitHub → Cloudflare Pages → Cowork)
정적 파일이라 **Cloudflare Workers는 불필요**. Pages(정적 호스팅)만 사용.
1. GitHub 저장소 = 원본. 루트에 `index.html`, `README.md`.
2. Cloudflare Dashboard → Workers & Pages → Create → Pages → GitHub 연결 → repo 선택.
   - Build command: (비움) / Output directory: `/`
3. 이후 GitHub에 push 하면 `프로젝트명.pages.dev`로 30초 내 자동 재배포.
4. (선택) Custom domain: `weight.oohinsightlab.com` 서브도메인 연결.
5. 수정은 코워크에서 → 커밋/푸시 → Pages 자동 재배포.

## 7. 코워크에서 이어서 작업하는 법
1. 위 GitHub repo를 코워크에 연결(또는 로컬 폴더로 열기).
2. 이 `README.md`를 컨텍스트로 주고 `index.html`을 대상으로 지정.
3. 예: "index.html의 식사량 색을 바꿔줘 / 음주 통계에 연속 금주일수 추가해줘" → 수정 → 커밋 → 배포.

## 9. 주의
- 데이터가 브라우저 localStorage에만 있으므로, **브라우저 데이터 삭제 시 기록 소실**. 주기적으로 메뉴 → 백업(JSON) 권장.
- 기기 간 기록은 현재 백업 파일로만 이동 가능(8번 동기화 붙이기 전까지).
